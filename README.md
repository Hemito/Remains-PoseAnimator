# Аниматор пони — Remains: Unity

Инструмент для поз и анимаций пони из игры Remains: Unity.
Тело пони собрано из 17 рисунков оригинала. Двигать нужно только концы шести
цепочек: четыре ноги, голова и хвост. Изгиб, растяжение и стык с корпусом
подбираются из атласа — тысяч поз из анимаций оригинала.

## В браузере — без установки
Откройте страницу сайта (или `index.html`).
- Ставьте концы цепочек, поворачивайте корпус, правьте отдельные части, меняйте
  рисунки (подогнутое копыто, форма хвоста).
- Сохраняйте позы, собирайте анимацию по ключевым кадрам и проигрывайте её.
- Работа хранится в этом браузере. Чтобы не потерять её и передать другим,
  используйте «Скачать всю работу» и «Скачать анимацию (JSON)». Загружаются они
  обратно кнопками «Загрузить работу» и «Загрузить анимацию».
- При первом открытии загружаются позы и анимации проекта — с них удобно начать.

Скачанная анимация содержит каждый кадр готовыми положениями 17 частей и не
зависит от атласа, в котором её сделали. Ключи в файле нужны только для
дальнейшей правки.

## Локально — с сохранением в файлы и для нейросетей
Нужен [Node.js](https://nodejs.org) 18 или новее, внешние пакеты не требуются.

    node server/server.mjs

Затем откройте http://127.0.0.1:8770. Работа сохраняется в папку `work/`.

Для нейросетей с поддержкой MCP (например, Claude Code) в корне есть `.mcp.json`:
сервер `pony-animator` запускается командой `node server/mcp.mjs`. Инструкция
для нейросети — `server/GUIDE.md`. У каждой нейросети свой сеанс. Её работу
видно на странице, открытой с `?session=<имя сеанса>`. Имя сеанса сообщает
команда `describe`.
Для автоматических картинок нужен установленный Chrome или Edge.

## Права
Рисунки пони взяты из игры Remains (Empalu) и используются с разрешения автора.
Это не значит, что они свободно лицензированы: для другого использования нужно
отдельное разрешение правообладателя.
